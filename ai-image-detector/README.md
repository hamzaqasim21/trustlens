# TrustLens — AI-Generated Profile Image Detector

Module 6.7 of the TrustLens FYP · Ali Ahmad (231667) · Air University Islamabad · FCAI 2025-26

Decides whether a profile picture is a real photograph or an AI-generated face. Before
classifying, it checks whether the image contains a human face at all, so pets, logos and
objects are never given a verdict.

```
image
  |
  |-- Stage 0  face gate (MTCNN)
  |      no face  -> "NOT A PERSON"
  |      face     -> crop with 0.35 margin
  |
  '-- Stage 1  frozen CLIP ViT -> probe -> REAL / AI-GENERATED / UNCERTAIN
```

## Results

Two detectors trained on the same real images and the same number of fakes. The only
difference is the diversity of the fake images.

| Test set | A — GAN only | B — mixed (this module) |
|---|---|---|
| GAN (StyleGAN) | 95.65% | 93.23% |
| Diffusion (Stable Diffusion) | 50.00% | 94.00% |
| Face-swap | 50.10% | 90.52% |

Training on GAN fakes alone does not transfer to diffusion generators. False-positive rate
of model B on the diffusion set is 8.55% (171 of 2,000 real photos).

### Accuracy vs image size

| Size | 320px | 224px | 160px | 128px | 96px |
|---|---|---|---|---|---|
| Accuracy | 92.3% | 90.2% | 89.1% | 89.2% | 69.5% |

Instagram serves profile pictures at roughly 150–320px. Below ~128px accuracy drops, so the
module returns `UNCERTAIN` on very small faces.

## Method

The backbone is a frozen CLIP Vision Transformer. It is not fine-tuned — only a small
classifier is trained on its features. A CNN fine-tuned on one generator learns that
generator's artifacts and fails on new ones, whereas CLIP's pretrained features transfer to
unseen generators (Ojha et al., *Towards Universal Fake Image Detectors*, CVPR 2023).

| Class | Sources |
|---|---|
| Real | FFHQ (140k Real & Fake Faces), IMDB-WIKI (DeepFakeFace) |
| AI-generated | StyleGAN, Stable Diffusion v1.5, SD inpainting, InsightFace face-swap |

Training applies random downscaling to 128–320px and JPEG re-compression at quality 40–90,
so the model sees inputs comparable to real profile pictures.

## Running locally

```
pip install -r requirements.txt
streamlit run app.py
```

Requires `artifacts/image_probe.pkl`, `artifacts/image_scaler.pkl` and
`artifacts/image_meta.json`, which the training notebook writes to Google Drive.

Python 3.11 is recommended; on 3.13 install the face detector separately with
`pip install --no-deps facenet-pytorch`, otherwise the OpenCV cascade in `assets/` is used.

## Output

```json
{
  "band": "fake",
  "verdict": "AI-GENERATED FACE",
  "face_detected": true,
  "confidence": 0.94,
  "p_ai": 0.94,
  "image_risk": 94,
  "face_size": "312x312",
  "reason": "Face detected and analysed. P(AI-generated) = 94.0%."
}
```

`image_risk` feeds the Trust Score Engine at 10% weight. A `fake` verdict with confidence
≥ 0.90 raises the kill-switch. `not_applicable` means the picture is not a face and the
module contributes nothing to the score.

## Limitations

- Diffusion training data is Stable Diffusion; Midjourney and Flux are unseen and score lower.
- Detection weakens as new generators appear, so the model needs periodic retraining.
- Non-face pictures cannot be scored.
- Faces below ~128px return `UNCERTAIN` rather than a verdict.
- A genuine photograph reused on a fake account is authentic at pixel level; catching that
  needs reverse image search, not forensics.
